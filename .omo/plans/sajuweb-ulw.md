# 사주 웹 ULW 실행 계획

## 근거와 범위

- 입력: `saju_web_PRD_v1.0.md` 전체 1~19절. 기존 소스와 git 저장소는 없다.
- ULW는 탐색 → 결정이 기록된 계획 → 구현 → 증거 검증으로 실행한다. 현재 세션에는 ULW 전용 명령/에이전트가 없어 이 파일을 실행 원장으로 사용한다. 사용자는 계획 작성과 실행을 함께 요청했다.
- 엔진은 재작성하지 않고 MIT `lunar-javascript@1.7.7`을 고정 사용한다. 기준 commit: `4c45a59f79b856125516f31aefa8295035c16afd`.
- 개발 기본값: 한국어, 양력, Asia/Seoul, 현지 민간시계 일시주 + UTC+8 절입 연월주, dayBoundarySect=2, yunSect=2. 학파 승인을 가장하지 않는다.
- 외부 승인 없는 비공개 개발 체험이다. 결제·LLM 호출·글로벌 정확성·검수된 개인화 상담은 공개 출시 상태로 표시하지 않는다.

## 작업 의존성과 수용 기준

### A. 기반
- [x] React + Vite 프런트와 Node/Express authoritative API를 구성한다.
- [x] 버전 고정과 lockfile, 오픈소스 고지, SBOM 명령을 제공한다.
- [x] 360px 모바일/데스크톱, 키보드 폼, 읽기 모드, 오류 후 입력 보존을 구현한다.

### B. 계산
- [x] validator → timezone normalizer → dual-context adapter → JSON DTO를 분리한다.
- [x] 역사 offset, DST gap/fold 거절 및 명시 offset 선택을 구현한다.
- [x] 천간/지지/지장간/십성은 canonical 일간으로 재산출한다.
- [x] 시간 미상은 시주 null, 절입 전후 후보 공통 사실만 제공한다.
- [x] 12절 -1/0/+1초, 23시/자정 sect1/2, 동시간대 비교, DST, 재현성을 테스트한다.
- [x] 대운은 숫자 0/1 명시 선택 시에만 기술 미리보기, 준비구간 null 및 본대운 10개와 연도 라벨을 제공한다. 정밀 현지 기운 시작일은 검수 전 미제공한다.
- [x] 연간 12개월은 UTC 절입 instant로 분할한다. 절월 index를 양력 월에 붙이지 않는다.
- [x] 지원 정책을 개발 검증 매트릭스로 명시하고 미지원 연도/zone/음력/진태양시를 차단한다.

### C. 제품 체험
- [x] 홈, 목적별 10개 상품 목록/상세, 프로필 입력/재확인, 명식/무료 요약, 리포트, 궁합, 서재를 연결한다.
- [x] P01~P04 무료 체험을 구현한다. P02 연도 불변, P03 상대 없이 생성, P04 상대 권한 확인과 대칭 관계 사실을 지킨다.
- [x] P05~P10 각각 고유 질문·목차·제한과 준비 상태를 표시한다. 승인 전 판매는 차단한다.
- [x] fact/rule 참조와 사실/전통 해석/일반 가이드를 분리한다. 규칙은 미검수 초안이며 무료 개발 체험으로 표시한다.
- [x] P07 접촉 거절/차단 분기는 생성·결제보다 먼저 안전 안내로 전환한다.
- [x] 미구현 확률·궁합점수·용신을 null로 유지하고 유료 API를 명시 차단한다.
- [x] 계정 대신 게스트 HttpOnly 세션 권한, 24시간 TTL, 동의 저장, 삭제 연쇄, 익명 공유 7일/즉시 철회를 구현한다.
- [x] 입력/결과를 로그와 URL에 노출하지 않는다. 세션 저장은 개발용 메모리이며 재시작 시 삭제된다.

### D. 검증
- [x] Node 엔진/콘텐츠/API 권한·중복 요청·삭제·공유·게이트 테스트를 통과한다.
- [x] TypeScript 검사와 프로덕션 번들 빌드를 통과한다.
- [x] Playwright에서 실제 입력→명식→리포트→저장→삭제와 모바일/데스크톱 화면을 확인한다.
- [x] README에 실행법, 구현/미구현 경계, 출시 게이트와 테스트 증거를 기록한다.
