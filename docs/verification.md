## 실제 브라우저 여정

1. 홈 → 별칭·생년월일·시간 → 최종 재확인 → 원국 → 무료 리포트 → 동의 저장 → 익명 공유/철회 → 안내 질문 → 서재 → 연쇄 삭제.
2. 시간 미상 입춘일 → 불확실한 연월주 안내 → 연간 12개월 → 실제 입춘 경계 표시.
3. 10개 상품 목록 → P07 연락 차단 안내 → 미출시 버튼 비활성 → 상대 미선택 궁합 차단.
4. 두 프로필 생성 → 상대 권한 동의 전 버튼 차단 → 동의 후 실제 궁합 리포트.
5. 뉴욕 DST gap 오류 → 입력 유지 → fold 오류 → offset 선택 → 명식 생성.

- 영어·추가 지역·한국 음력·진태양시·정밀 대운 날짜.
